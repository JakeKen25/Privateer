# Admiral Manager

Right-click the player nation and choose **Admiral Manager**. It is available
only for Nation0, the player slot. Edit **Admiral name** or **Prestige**, then
choose **Apply** to stage the validated changes in memory. **Cancel** discards
this dialog's changes. Use **Save** or **Save As** in the main window to write
them with the normal validation and backup workflow.

This edits the stored `AdmiralName` and `Prestige` values. It is not an officer
roster editor and does not create, transfer or assign ship commanders.
