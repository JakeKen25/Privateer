# Privateer 1.0.3 Beta — local test build

Adds Ship Spawner > Import from SDF file. Import 1–100 completed ships with automatic
Privateer TYPE N names and one numbered class per batch. Changes are staged until
Apply and written only by Save/Save As. Aircraft capacity is permitted without
creating aviation records. Supports current SDF exports and the common legacy layout
used by installed RTW3 ship designs. Unknown layouts and non-ship designs remain
unsupported; see SHIP_SPAWNER.md for technical limits and validation status.

No public release or tag was created for this build. Published release remains 1.0 Beta.

Custom designs uses the Custom Files folder beside the configured Save folder.
Installed designs uses Designs beneath the configured game installation.
