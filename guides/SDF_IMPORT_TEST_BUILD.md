# Privateer 1.0.1 Beta — release build

Adds editable ship names and class names to Ship Spawner > Import from SDF file.
The suggested Privateer TYPE N ship names and numbered class name are prefilled;
each imported ship has its own name field, and changing the copy count adds or
removes corresponding fields. Changes are staged until Apply and written only by
Save/Save As. Aircraft capacity is permitted without creating aviation records.
Supports current SDF exports and the common legacy layout used by installed RTW3
ship designs. Unknown layouts and non-ship designs remain unsupported; see
SHIP_SPAWNER.md for technical limits and validation status.

This build is published as the 1.0.1 Beta prerelease.

Custom designs uses the Custom Files folder beside the configured Save folder.
Installed designs uses Designs beneath the configured game installation.
